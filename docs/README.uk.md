# Документація 2mux

[English version](README.md) · [README проєкту](../README.uk.md)

2mux відкриває виконавця Codex і рев’юера Claude Code у спільному проєкті та доставляє їхні повідомлення через локальну чергу й міст tmux.

| Документ | Що в ньому знайдете | English |
| --- | --- | --- |
| [Посібник користувача](guide.uk.md) | Збирання, встановлення, запуск, рев’ю завдання, повторне підключення та діагностика доставки. | [User guide](guide.md) |
| [Довідник CLI](cli.uk.md) | Команди, параметри, визначення відправника, обмеження повідомлень, квитанції та відновлення. | [CLI reference](cli.md) |
| [Архітектура та розробка](architecture.uk.md) | Карта коду, належність сесій, стани черги, блокування процесів і перевірки. | [Architecture and development](architecture.md) |

Зафіксоване рев’ю від 30 вересня 2026 року та межі його перевірок описано в [REVIEW.uk.md](../REVIEW.uk.md). Історичний живий тест має [збережені квитанції](../validation/live-review-20260930.json).

У прикладах `2mux` встановлено в `PATH`. Команди проєкту виконуйте з каталогу, над яким мають працювати агенти. Умовні шляхи та ID повідомлень замінюйте значеннями власної сесії.
